04

Why can a skill be selected but still not finish?

Selecting a method is not executing it. The host must supply a permitted operation and its prerequisites; the returned result must still satisfy the task. Instruction-only work can skip execution altogether.

Capabilities and permission disposition

Host runtime→Execution coordination

Before an operation is requested, the host provides which tools are available and whether the intended action is allowed. A matching skill does not supply that authority.

07

What travels, and what depends on the host?

The folder format travels. Discovery, tool availability and permission behavior still depend on the host. agentskills.io defines the format; OpenAI documents Codex behavior. They are not interchangeable authorities.

Host integration remains specific

Check the receiving host for package locations, duplicate-name handling, trust filtering and implicit invocation settings before assuming a shared folder behaves identically there.
